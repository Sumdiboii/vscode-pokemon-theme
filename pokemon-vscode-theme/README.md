# Game Boy Pokémon Light

A minimal, retro handheld-inspired light theme with Deep Crimson chassis
framing and Pikachu Gold accents.

Created by [Sumedh Pimplikar](https://sumedhpimplikar.vercel.app/).

## The Pokédex aesthetic

The theme frames the editor with a Deep Crimson Activity Bar and status bar,
then uses a soft Game Boy shell canvas and matte handheld panels to keep long
coding sessions comfortable. Crisp Charcoal typography, hardware-style panel
dividers, gold focus details, and a Great Ball Azure file selection add depth
without overwhelming the code.

## Install from source

1. Run `npx @vscode/vsce package` from this directory.
2. In VS Code, open **Extensions: Install from VSIX...**.
3. Select the generated `.vsix` file.
4. Open the Command Palette and choose **Preferences: Color Theme**.
5. Select **Game Boy Pokémon Light**.

## Package the extension

```bash
npx @vscode/vsce package
```
