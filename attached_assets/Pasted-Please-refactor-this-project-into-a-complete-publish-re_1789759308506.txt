### 2. Design & Color Palette Rules
Apply these exact tokens inside `themes/gameboy-pokemon-color-theme.json`:

Tokens:
- Main Canvas: #F0F0EA (Game Boy Shell Gray)
- Panels/Sidebar: #E4E4DC (Matte Handheld Gray)
- Primary Text: #2B2D42 (Charcoal Black)
- Primary Accent: #9E1B1B (Deep Crimson)
- Secondary Accent: #D99B26 (Pikachu Gold)
- Borders: #9E9E94 (D-Pad Gray)
- Syntax Green: #4A7C59 (Comments/Strings)
- Syntax Blue: #2B6CB0 (Methods/Types)
- Syntax Purple: #6B46C1 (Keywords/Control Flow)

UI Rules:
1. Pokédex L-Chassis:
   - Leftmost Strip (activityBar.background): Solid Deep Crimson (#9E1B1B). Set active icons to #FFFFFF and inactive icons to translucent white. Set notification badges (activityBarBadge.background) to Pikachu Gold (#D99B26) with Charcoal text (#2B2D42).
   - Bottom Bar (statusBar.background): Solid Deep Crimson (#9E1B1B) with #FFFFFF text.
2. Panels & Canvas:
   - Editor background: #F0F0EA.
   - Sidebar background: #E4E4DC.
   - 1px solid borders (#9E9E94) between all major panels.
3. Selections & Tabs:
   - Sidebar File Selection (list.activeSelectionBackground): Deep Crimson (#9E1B1B) with #FFFFFF text. Hover state: #E0E0D8.
   - Active Tab: #F0F0EA with a 2px top border in Deep Crimson (#9E1B1B).
   - Inactive Tabs: #E4E4DC.
   - Active line numbers & cursor: Pikachu Gold (#D99B26).
